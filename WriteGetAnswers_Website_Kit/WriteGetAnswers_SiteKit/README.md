# Write Get Answers download website kit

This folder contains a static landing page plus the Write Get Answers 2.5.0 extension package.

## What is included
- `index.html` — premium dark/gold landing and download page
- `assets/logo.jpg` — logo copied from the extension package
- `downloads/WriteGetAnswers_2_5_0.zip` — Chrome extension upload package

## Publish for free with GitHub Pages
1. Create a **public** GitHub repository (for example `write-get-answers-download`).
2. Upload the contents of this folder to the repository's root. Ensure `index.html` is at the root, not nested inside another folder.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then save.
5. Wait until GitHub Pages reports the website is published. The page URL will look like `https://YOUR-USERNAME.github.io/write-get-answers-download/`.
6. Visit the published URL. The QR section will generate a QR code for that public URL. Click **Open / save QR image** and save the image.

GitHub Pages is free for public repositories. Keep the repo public because the site and its extension download are intended to be publicly accessible.

## Important
A public QR code cannot be finalized from a local file or a ChatGPT sandbox link. The QR generated by this page is enabled only once the page has a public HTTPS address. Until you publish this site, do not share a QR made from a local preview; it will not work for other devices.

The QR image uses the external `api.qrserver.com` image service and includes only the public page URL. The download link on the page points to the ZIP in this same website package.
